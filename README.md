# Cobrinha Neon

Jogo da cobrinha com visual neon, feito em um único arquivo HTML (sem dependências). Funciona no computador e no celular.

## Como jogar

- **Mover (computador):** setas do teclado `↑` `↓` `←` `→` ou `W` `A` `S` `D`.
- **Mover (celular):** deslize o dedo na tela.
- **Iniciar / pausar / recomeçar:** `Espaço` (ou toque na tela). `P` também pausa.
- Coma as bolinhas rosas para ganhar pontos. A cobra cresce e fica mais rápida a cada ponto.
- As bordas são conectadas: sair por um lado faz a cobra voltar pelo lado oposto.
- O jogo termina se a cobra bater no próprio corpo.
- O **recorde** fica salvo no navegador (`localStorage`).

## Como rodar

Não precisa instalar nada. Abra o arquivo [`index.html`](index.html) em qualquer navegador moderno.
